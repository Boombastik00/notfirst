# не первая

бесплатная открытая платформа историй женщин: проверенные биографии и живой
личный опыт, с которыми можно соотнести свою ситуацию — и увидеть, что ты
не первая, кто через это проходит

## зачем

когда девушка сомневается — «я самозванка в профессии», «поздно менять сферу»,
«в моей стране так не выйдет» — ей нужны не абстрактные советы, а истории
других женщин, которые прошли похожий путь. подбор работает на обычной
прозрачной фильтрации по тегам (сомнение, профессия, страна, сфера) с
объяснением «почему именно эта история», без нейросетей и скрытых алгоритмов

проект бесплатный, без рекламы, без продажи данных, 12+, с открытым кодом
(эта страница) и открытой лицензией на истории

## что умеет

- каталог историй с фильтрами и поиском, история дня
- подборки по переживаниям: отмечаешь что отзывается — получаешь истории с
  объяснением совпадений
- свои истории от пользовательниц с модерацией перед публикацией
- официальные истории — проверенные биографии с обязательными источниками,
  пишут авторки с бейджем
- профили с бейджами (создательница, модераторша, авторка, разработчица,
  дизайнерка), публичные истории авторок, поиск по аккаунтам
- избранное, онбординг, персональный профиль
- юридический слой: согласия с журналом, документы прямо на сайте

комментарии пока не реализованы — появятся отдельным этапом, с премодерацией

## принципы

- без ИИ для подбора: только объяснимая фильтрация, каждую рекомендацию
  можно раскрыть и увидеть почему
- минимум персональных данных: вход через google, из данных — имя, email,
  аватар; email не показывается никому кроме самой владелицы
- двенадцать плюс
- открытость: код под MIT, истории под CC BY-SA 4.0

вход через google и панель персонала включаются по инструкции
docs/GOOGLE_OAUTH.md (нужен свой oauth-клиент в google cloud console)

## статус

полный MVP: каталог исторей с фильтрами и поиском, история дня, персональные
подборки, онбординг, профиль, избранное, публикация пользовательских исторей
с модерацией, официальные истории с источниками, публичные профили, бейджи
персонала, баны, поиск по аккаунтам, юридические документы с журналом согласий

## стек

- backend: python 3.12 fastapi uv
- frontend: next.js 15 typescript pnpm
- база данных: postgresql 16
- инфраструктура: docker compose github actions

## быстрый старт через docker

нужны docker и docker compose

    docker compose up --build

- лендинг: http://localhost:3000
- healthcheck через прокси фронтенда: http://localhost:3000/api/v1/health
- api напрямую: http://localhost:8000/api/v1/health

## локальная разработка без docker

backend (нужен uv):

    cd backend
    uv sync
    uv run uvicorn app.main:app --reload

frontend (нужны node 20+ и pnpm):

    cd frontend
    pnpm install
    pnpm dev

бэкенд ожидается на localhost:8000 фронтенд проксирует /api/v1 туда сам

## миграции и демо-данные

база должна быть запущена (`docker compose up -d db`)

    cd backend
    uv run alembic upgrade head
    uv run python -m app.seed

сид идемпотентный: повторный запуск обновляет словари и демо-истории и убирает
устаревшие демо-записи. то же самое внутри контейнера api:

    docker compose exec api sh -c "/app/.venv/bin/alembic upgrade head && /app/.venv/bin/python -m app.seed"

## тесты и линтеры

    cd backend && uv run ruff check . && uv run pytest
    cd frontend && pnpm lint && pnpm build
    cd frontend && pnpm test            # vitest для компонентов
    cd e2e && uv run pytest             # playwright e2e против запущенного сайта

e2e-тесты ожидают поднятыми docker compose стек и базу, внутри себя создают
сессию тестовой модераторши в базе поэтому google для них не нужен

## прод-деплой

нужен домен и две записи dns на сервер (A и AAAA), затем:

    cp .env.example .env.prod           # заполнить продовыми значениями
    export DOMAIN=nefirst.example       # ваш домен
    docker compose -f docker-compose.prod.yml --env-file .env.prod up --build -d

caddy сам получает сертификат lets encrypt и держит https. в .env.prod
заполнить GOOGLE_CLIENT_ID/SECRET (redirect uri в google cloud console
добавить https://домен/api/v1/auth/google/callback), SESSION_COOKIE_SECRET
(случайная строка) и ADMIN_GOOGLE_SUBS
